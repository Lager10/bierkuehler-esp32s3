# CAD-Daten

Die mechanischen Daten des Bierkühlers werden in diesem Verzeichnis abgelegt.
Empfohlene Unterteilung:

```text
cad/
├── source/       bearbeitbare Originaldateien des verwendeten CAD-Programms
├── step/         herstellerunabhängige STEP-Exporte
├── stl/          druckfertige Einzelteile
└── drawings/     PDF- oder DXF-Zeichnungen
```

Zu jedem veröffentlichten Stand sollten mindestens das verwendete CAD-Programm
mit Versionsnummer, die Maßeinheit, Materialhinweise und das Exportdatum
dokumentiert werden.

Vor dem Hochladen bitte die Dateieigenschaften und Exportkopfzeilen auf Namen,
E-Mail-Adressen, lokale Dateipfade und externe Verknüpfungen prüfen. ZIP-Dateien
sind nur für komplette Downloadpakete sinnvoll; die eigentlichen Quelldateien
sollten nach Möglichkeit zusätzlich einzeln vorliegen.
